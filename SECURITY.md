# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 1.1.x   | ✅        |
| < 1.1   | ❌        |

## Reporting a Vulnerability

If you discover a security vulnerability in OSK, please report it by opening an issue on the OSK GitHub repository. Do not include sensitive details publicly — keep the report high-level and we will follow up.

## Bugs & Glitches

OSK is actively developed and you may encounter bugs or unexpected behaviour during normal use. This includes but is not limited to:

- Keys not responding or sending the wrong input
- The keyboard window not rendering correctly
- Layout or language switching issues
- Startup or shortcut problems
- Visual glitches or display issues on certain screen resolutions

If you run into anything like this, please open an issue on the GitHub repository and describe:
- What you were doing when it happened
- What you expected to happen
- What actually happened
- Your Windows version

All bug reports are read and appreciated. The more detail you provide, the faster it can be looked into.

## Disclaimer

OSK is provided as-is. While we take quality seriously and aim to keep the app stable, we cannot guarantee it will be free of bugs at all times. If something breaks, report it and we will do our best to fix it.
